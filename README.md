# Html Editor

Мобильный HTML-редактор для Android: пишите HTML, CSS и JavaScript и сразу смотрите результат.

## Возможности

- **3 вкладки сверху:** «Редактор» · «Обзор» · «Result»
- **Редактор кода** — подсветка HTML (теги, атрибуты, строки, комментарии), номера строк, моноширинный шрифт
- **Обзор** — открытие файла с устройства через системный выборщик (Storage Access Framework, без разрешений)
- **Сохранение** — «Сохранить» в текущий файл и «Сохранить как…» (создание нового файла)
- **Result** — предпросмотр в WebView. Обновляется по условию: изменения кода **минимум 2 символа** + **нажатие на вкладку Result** (или кнопку обновления)
- **Настройки** (кнопка `…` снизу справа на вкладке Result, открывается сверху):
  - режим **Телефон / ПК** (адаптивный вьюпорт против широкого 1280px и десктопный User-Agent)
  - **− / +** — размер страницы (50%…300%)
- Ориентация экрана — книжная/альбомная по повороту устройства (по умолчанию книжная)
- Черновик и настройки сохраняются между запусками

## Палитра

| Цвет | Назначение |
|------|------------|
| `#EDE4D0` | Основной — окно ввода кода, окно настроек |
| `#ECB1B3` | Сглаживающий — панели рядом с основным, номера строк, выделение |
| `#9F5165` | Второй основной, акцентный — активная вкладка, кнопки, FAB |
| `3C6970` | Верхний таб и остальные элементы — значки, панель вкладок |

Без градиентов, glow и неона — только плоские цвета.

## Технологии

- Kotlin + XML (View), минимально зависимостей
- `compileSdk` / `targetSdk` — **36**, `minSdk` — 24
- WebView для предпросмотра, SAF для файлов
- Без лишних разрешений (только `INTERNET` для загрузки ресурсов страниц)

## Сборка

1. Откройте проект в **Android Studio** (Ladybug/Otter или новее).
2. Дождитесь синхронизации Gradle (нужен JDK 17+, интернет — Gradle 8.13 и AGP 8.10.0 скачиваются автоматически).
3. **Build → Build App Bundle(s) / APK(s) → Build APK(s)**.

Или из командной строки:

```bash
./gradlew assembleDebug        # APK: app/build/outputs/apk/debug/app-debug.apk
./gradlew assembleRelease      # Release (нужна подпись)
```

## Структура

```
app/src/main/java/com/htmleditor/app/
├── MainActivity.kt        — вкладки, настройки, открытие/сохранение
├── CodeEditor.kt          — подсветка, номера строк, синхронная прокрутка
├── HtmlHighlighter.kt     — regex-подсветка HTML (только span, курсор не сбивается)
├── PreviewController.kt   — WebView: режим ПК/телефон, зум, загрузка кода
├── FileStore.kt           — чтение/запись файлов через SAF
├── TextDiff.kt            — подсчёт изменившихся символов (условие ≥ 2)
└── Prefs.kt               — черновик и настройки в SharedPreferences
```
